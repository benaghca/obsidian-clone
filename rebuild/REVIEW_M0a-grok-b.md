## Scope

M0a is the Rust half. `.cinder` is in `SKIP_DIRS` with `.obsidian`, `.git`, `.trash`, and `.grove`. List, search, the index, the watcher, and the note and path commands skip it, including a `.cinder` folder nested under another folder. Startup still sweeps abandoned `*.grove-tmp` files inside `.grove` and does not walk `.cinder`.

`read_foreign_config(source, name) -> Option<String>` is read-only and `#[tauri::command(async)]`, the same off-main-thread shape as `read_config`. The allowlist is an exact match and nothing else:

| source | name | file |
|---|---|---|
| `cinder` | `settings.json` | `.cinder/settings.json` |
| `obsidian` | `daily-notes.json` | `.obsidian/daily-notes.json` |
| `obsidian` | `templates.json` | `.obsidian/templates.json` |
| `obsidian` | `app.json` | `.obsidian/app.json` |

A missing file is `None`, and the read does not create the folder or the file. The bytes come back as stored text, including when they are not JSON. A directory, or a file over `CONFIG_MAX_BYTES` (1 MiB, the same cap as `read_config`), is refused. A `.cinder` or `.obsidian` folder, or the file itself, that canonicalizes outside the vault is refused through the same `ensure_inside` check `config_file` uses. There is no write command for these folders.

Wired through `build.rs`, `invoke_handler`, `capabilities/default.json` (`allow-read-foreign-config`), and `permissions/autogenerated/read_foreign_config.toml`. CONTRACT.md lists `.cinder` with the other skipped dirs and documents the command. No new crate or package. The front end does not call the command. That is M0b.

Section 11 of the plan is still a list of open choices. None of them changes this allowlist. Weekly and monthly keys, if Choice 1 later asks for them, already live inside `.cinder/settings.json`. Mapping them is M0b.
