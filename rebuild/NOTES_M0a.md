# NOTES_M0a — Cinder settings import, Rust half

Branch `rebuild/m0a-grok-a`, from `rebuild/integration` (`b5d0a34`). Rust only. M0b was not started. Nothing was pushed, and no window was opened.

## What changed

`.cinder` is now in `SKIP_DIRS` next to `.obsidian`, `.git`, `.trash` and `.grove`. List, search, the index, the watcher, and the note and path commands skip it, including a `.cinder` folder nested under another folder. Startup still sweeps abandoned `*.grove-tmp` files inside `.grove`. It does not walk `.cinder`, same as `.obsidian`, `.git` and `.trash`.

`read_foreign_config(source, name) -> Option<String>` is a read-only async command. The allowlist is an exact match:

| source | name | file |
|---|---|---|
| `cinder` | `settings.json` | `.cinder/settings.json` |
| `obsidian` | `daily-notes.json` | `.obsidian/daily-notes.json` |
| `obsidian` | `templates.json` | `.obsidian/templates.json` |
| `obsidian` | `app.json` | `.obsidian/app.json` |

Every other pair is an error. A missing file is `None`, and the read does not create the folder or the file. The text is returned as stored. It does not have to be JSON. A directory, or a file over 1 MB, is refused. A `.cinder` or `.obsidian` folder, or the file itself, that resolves outside the vault is refused. That is the same cap and symlink rule as `read_config`. There is no write command for these folders.

Wired through `build.rs`, `invoke_handler`, `capabilities/default.json` (`allow-read-foreign-config`), and `permissions/autogenerated/read_foreign_config.toml`. `CONTRACT.md` lists `.cinder` with the other skipped dirs and documents the command. No new crate or package. The ignored benches were left as they are and still compile.
